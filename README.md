# Cupid Pick 💘 — 왜 이 사람인지 보여주는 소개팅

바이브코딩 실습 4 「가장 잘 맞는 상대를 찾아줍니다」 결과물입니다.
소개팅 앱 화면보다 **매칭 로직**이 핵심이며, 추천 상대와 그 상대를 고른 이유를 화면에 보여줍니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. (설치 필요 없음)

**같은 와이파이의 휴대폰에서 쓰기 (AI 설명 포함)**: `../소개팅앱 서버 켜기.bat`을 더블클릭하거나 `python ../자기소개로컬LLM/serve.py`를 실행하고, 화면에 나온 `http://(내 컴퓨터 IP):8777` 주소를 휴대폰 브라우저에 입력한다. 서버가 앱 화면을 보내 주고, 휴대폰의 AI 요청을 내 컴퓨터의 Ollama에 대신 전달한다 (대화 기능만 허용).

## 매칭 로직

자세한 점수표와 이유는 [점수표.md](점수표.md)에 있습니다.

1. **거르기** — 나 자신, 같은 성별, 내가 **꼭**으로 표시한 이상형 조건에 안 맞는 사람은 제외
2. **점수 (만점 100)** — 관심사 30 · 외모 스타일 15 · 지역 15 · 나이 10 · 키 근접도 10 · 연봉/종교/비흡연/MBTI 각 5
3. **양방향** — 상대의 이상형(`ideals.js`)으로 나도 채점해서, 내가 보는 점수와 상대가 보는 점수의 **평균**으로 순위를 정함
4. **이유** — 1위 카드에 "무엇으로 몇 점을 받아 1위인지"와 2위와의 점수 차이를 문장으로 보여줌

## 로컬 AI (임베딩 + 로컬 LLM)

인터넷 AI 대신 **내 컴퓨터의 Ollama**로 돌린다. 만드는 스크립트는 옆 폴더 `../자기소개로컬LLM/`에 있다.

| 기능 | 모델 | 방식 | 공개 사이트 |
|---|---|---|---|
| 비슷한 관심사 점수 (등산↔캠핑) | `bge-m3` 임베딩 | `make_embeddings.py`로 미리 계산 → `embeddings.js` | ✅ |
| 프로필 자기소개 24명 | `exaone3.5:2.4b` | `make_intros.py`로 미리 생성 → `intros.js` | ✅ |
| 1위 이유를 AI가 말로 설명 + 데이트 추천 | `exaone3.5:2.4b` | 내 로직 화면 버튼 → Ollama에 바로 질문 | ❌ Ollama가 켜진 컴퓨터에서만 |

- 점수와 순위는 **점수표로만** 정한다. AI는 자기소개를 쓰고, 이미 나온 결과를 말로 풀어 줄 뿐 순위를 바꾸지 않는다
- 작은 모델(2.4b)이라 규칙을 잘 어겨서, **예시 1개를 보여 주고**(few-shot) 결과를 **코드로 한 번 더 정리**한다 (이모지·반말·긴 문장 제거)

```
ollama pull bge-m3
ollama pull exaone3.5:2.4b
cd ../자기소개로컬LLM
python make_embeddings.py   # 관심사가 바뀌면 다시 실행
python make_intros.py       # 프로필이 바뀌면 다시 실행
```

## 기능

- 회원가입 / 로그인 (데모: 브라우저에만 저장), 프로필 사진 올리기 또는 기본 이미지 선택
- 내 프로필과 이상형 선택, 항목별 **꼭(필수)** 지정
- 추천 카드 스와이프, 하트 보내기(사진 더블클릭 가능), 매칭
- 1:1 채팅 (가상 프로필이 자동으로 답장)
- 양방향 매칭: 카드마다 내가 보는 점수 · 상대가 보는 점수 · 평균
- 내 로직 화면: 거르기 결과, 점수표, 양방향 설명, 전체 순위, AI 설명 듣기
